你现在要在当前空文件夹中初始化并开发一个名为 history-map-sandbox 的前端项目。这个项目是一个“历史地图沙盘”，当前阶段主要展示中国历史战争/战役案例，但架构不能写死战争，要支持未来扩展到历史事件、疆域变迁、迁徙路线、贸易路线、人物行迹、城市历史等场景。

一、技术栈要求

使用：
- Vue 3
- TypeScript
- Vite
- Vue Router
- Pinia
- CesiumJS
- dayjs
- @turf/turf
- npm 作为包管理器
- GitHub Actions + GitHub Pages 部署

不要使用后端。第一版所有数据都从 public/data 里的 JSON 和 GeoJSON 静态文件读取。

注意：
- 当前文件夹就是项目根目录，不要再创建 history-map-sandbox 子文件夹。
- 项目内部模块优先使用文件顶部静态 import，不要随便在函数里 await import(...) 动态导入。
- 不要提交 dist、node_modules、.env.local。
- 要生成 package-lock.json。
- 页面要能通过本地浏览器访问固定端口快速查看。

三、路由要求

使用 hash router，避免 GitHub Pages 刷新子路由 404。

路由：
/
#/scenario/:id
#/about

GitHub Pages 仓库名是 history-map-sandbox，因此 Vite base 使用：
/history-map-sandbox/

本地开发访问地址应该是：
http://localhost:5173/history-map-sandbox/#/

生产预览访问地址应该是：
http://localhost:4173/history-map-sandbox/#/

四、package.json 脚本要求

请提供这些脚本：

dev：vite --host 127.0.0.1 --port 5173
dev:lan：vite --host 0.0.0.0 --port 5173
build：vue-tsc -b && vite build
preview：vite preview --host 127.0.0.1 --port 4173
preview:lan：vite preview --host 0.0.0.0 --port 4173
typecheck：vue-tsc --noEmit
lint：eslint . --ext .vue,.ts
format：prettier --write .

五、Vite + Cesium 配置要求

vite.config.ts 中要：
- 使用 @vitejs/plugin-vue
- 使用 vite-plugin-static-copy 复制 Cesium 静态资源
- 复制 node_modules/cesium/Build/Cesium/Workers
- 复制 node_modules/cesium/Build/Cesium/ThirdParty
- 复制 node_modules/cesium/Build/Cesium/Assets
- 复制 node_modules/cesium/Build/Cesium/Widgets
- 输出到 cesiumStatic
- define CESIUM_BASE_URL 为 /history-map-sandbox/cesiumStatic/
- base 设置为 /history-map-sandbox/

六、CesiumViewer 要求

CesiumViewer.vue 要实现：
- 初始化 Cesium Viewer
- 引入 cesium/Build/Cesium/Widgets/widgets.css
- 默认定位到平型关一带
- 允许传入 places、routes、zones 数据
- 渲染地点点位
- 渲染路线
- 渲染区域
- 支持图层显示/隐藏
- 组件卸载时销毁 viewer
- 没有 Cesium Ion token 时也要能打开页面，不要因为 token 缺失导致整个页面崩溃

.env.example 中写：
VITE_CESIUM_ION_TOKEN=
VITE_TDT_TOKEN=

第一版可以不强制启用真实地形。代码里保留 Cesium Ion token 配置入口，有 token 时后续可扩展地形；没有 token 时使用默认地球或无地形模式，并在界面上显示“当前为基础地图模式”。

八、数据模型要求

public/data/scenarios.json 示例：

[
  {
    "id": "pingxingguan",
    "title": "平型关大捷",
    "category": "战争战役",
    "period": "1937年9月",
    "location": "山西省灵丘县一带",
    "summary": "用于演示历史地图沙盘的数据样例，具体史实坐标需后续校订。",
    "cover": "/icons/marker-place.svg"
  }
]

metadata.json 要包含：
id
title
category
startDate
endDate
center
defaultCameraHeight
summary
tags
factions

events.json 要包含多个时间轴事件：
id
time
title
description
focus
visibleLayers

places.geojson：
FeatureCollection，包含几个 Point 点位，例如平型关、灵丘、伏击区域附近关键点。
properties 中包含 id、name、type、description、startTime、endTime。

routes.geojson：
FeatureCollection，包含 LineString。
properties 中包含 id、name、type、faction、description、startTime、endTime。

zones.geojson：
FeatureCollection，包含 Polygon。
properties 中包含 id、name、type、faction、description、startTime、endTime。

sources.json：
写明这是演示数据，正式数据需要补充史料来源、地图来源、坐标校订说明。

九、时间轴要求
