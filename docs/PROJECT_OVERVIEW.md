# 项目概览

## 项目背景

History Map Sandbox 旨在把历史叙事放回空间和时间中展示。第一版用静态数据、三维地图和时间轴做最小可用原型，验证专题列表、场景页、图层控制、事件播放和资料说明的基本流程。

## 为什么叫 History Map Sandbox

Sandbox 表示这个项目不是单一专题页面，而是可持续添加专题、图层和叙事方式的历史地图沙盘。它可以容纳不同历史主题，也允许后续逐步增加更精确的数据和交互能力。

## 当前阶段目标

- 建立 Vue 3 + TypeScript + Vite 的静态前端项目。
- 接入 CesiumJS，完成点、线、面图层渲染。
- 通过 `public/data` 读取专题数据。
- 实现首页、场景页、关于页和基本文档。
- 使用 GitHub Actions 部署到 GitHub Pages。

## 未来扩展方向

- 历史事件的多阶段空间演变。
- 疆域、行政区划和边界变化。
- 人群迁徙、商贸线路、交通网络。
- 人物行迹、城市历史和地点关系。
- 更严谨的数据校订、参考文献和版本管理。

## 不局限于战争

当前样例使用战争/战役数据，是因为点、线、面和时间轴关系清晰，便于验证沙盘能力。项目的数据模型和组件命名避免绑定战争语义，后续可扩展到更广义的历史地理与历史事件可视化。
